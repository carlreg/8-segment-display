② 8 个小灯：逐段控制 点击小灯 或 点击屏体笔画
位段对应：DP→bit7，g→bit6，f→bit5，e→bit4，d→bit3，c→bit2，b→bit1，a→bit0。 段码值就是这 8 个灯的开关状态按位组成的字节。
③ 驱动方式：共阴 / 共阳 观察电平取反

对应逻辑
1 点亮
共阴：公共端接 GND，段引脚给高电平点亮，段码位 1 = 亮（共阴码）；
共阳：公共端接 VCC，段引脚给低电平点亮，段码位 0 = 亮（共阳码 = 共阴码按位取反）。
④ 段码真值表 高亮行 = 当前显示
字符共阴 Hex共阴二进制 (DP g f e d c b a) abcdefgDP
段码速记：a=bit0 … g=bit6、DP=bit7。例如 0 = a+b+c+d+e+f = 0x3F； 1 = b+c = 0x06；8 = 全部 7 段 = 0x7F（俗称“8 字全亮”）； 再加 DP 就是 0xFF，即 8 个灯全亮。
